# EcoTote

## *Eco-friendly bags — Style that doesn't harm the planet*

EcoTote is a modern, clean and fully responsive **landing page** for a brand of ecological tote bags. The project showcases high-quality UI/UX, smooth animations, and professional front-end development.

---

## Features

- **Modern & minimalistic design** focused on ecology and sustainability
- **Fully responsive** — perfect on mobile, tablet, and desktop
- **Smooth animations** and interactive elements
- **Fast performance** built with Vite
- **Clean & modular code** structure
- **SEO-friendly** semantic HTML

---

## Tech Stack

- **[HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML)** — Semantic markup
- **[SCSS / CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS)** — Modern styling and responsiveness
- **[JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)** — Interactivity and animations
- **[Vite](https://vitejs.dev/)** — Fast build tool and development server
- **Mobile-first & Responsive** design
